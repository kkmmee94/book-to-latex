# Contributing

Thank you for improving Book to LaTeX.

1. Create a focused branch.
2. Install `.[dev]`.
3. Add or update tests with the change.
4. Run Ruff, the full unit suite, and `python -m build`.
5. Explain user-visible behavior and disk/network effects in the pull request.

Visible options must use nontechnical names and provide a hover/help description. Do not commit source documents, generated page images, AI model weights, API keys, or personal filesystem paths.
